# Connor Lin's website

The reconstructed Hugo source is in `hugo/`. The HTML and assets at the repository
root are the published GitHub Pages site and remain available as the reference
for the reconstruction. Builds use the source in this repository and need no
sibling checkout, Git submodule, or external theme download.

## Build and preview

Use **Hugo 0.55.6 extended**, which is installed on this machine as
`hugo-0.55.6`. The newer Homebrew `hugo` executable is incompatible with this
version of Academic.

```sh
./scripts/build.sh
./scripts/build.sh server --bind 127.0.0.1 --port 1313
```

Build output goes to `.hugo-build/`. The preview is at http://localhost:1313/.
Building does not replace the published HTML at the repository root.

## Deployment

GitHub Pages publishes the root of the `master` branch at `connorzlin.com`.
Pushing updated HTML and assets to that branch triggers publication. The
`.nojekyll` file tells Pages to serve the static files without processing the
Hugo source as Jekyll content.

There is no custom Hugo GitHub Actions workflow. A source-only edit does not
rebuild the published HTML automatically: build and update the corresponding
root files before pushing. `.hugo-build/` is only local preview output.

## Edit the site

| Content | Source |
| --- | --- |
| Biography, role, affiliations, interests, education, social links | `hugo/content/authors/admin/_index.md` |
| Profile photo | `hugo/content/authors/admin/avatar.jpg` |
| Experience timeline | `hugo/content/home/experience.md` |
| Publications | `hugo/content/publication/<paper>/index.md` |
| Homepage section order and layout | `hugo/content/home/*.md` |
| Projects and thesis post | `hugo/content/project/`, `hugo/content/post/` |
| CV | `hugo/static/files/cv.pdf` |
| Navigation and site settings | `hugo/config/_default/` |
| Template overrides | `hugo/layouts/` |

The CV source contains the supplied `F26_Resume.pdf`. For an immediate change to
the published checkout, also replace `files/cv.pdf`; normal source builds copy
the source CV into `.hugo-build/files/cv.pdf`.

The publication list, individual paper pages, author pages, search index, feeds,
and sitemap are generated by Hugo from the recovered content. Biography and
experience descriptions retain HTML where that preserves the published markup;
they can be edited directly inside their Markdown files.

The Academic theme is vendored in `hugo/themes/academic/` with its license.
The published CSS and JavaScript bundles are retained to preserve the current
appearance and behavior. See [recovery notes](hugo/RECOVERY.md) before changing
styles or upgrading Hugo.

## Verify the reconstruction

```sh
./scripts/build.sh
python3 scripts/verify-build.py
```

The verification uses only Python's standard library. It compares all 44
published page routes and their primary visible content, checks local links,
compares search-index page titles and routes, and checks the CV and custom
domain. For the homepage, it compares the entire visible body, including
navigation and all three sections. The reference is the published HTML in this
checkout; intentional content changes will report differences against it.

## Install the compatible Hugo on another macOS machine

Download `hugo_extended_0.55.6_macOS-64bit.tar.gz` and
`hugo_extended_0.55.6_checksums.txt` from the
[official release](https://github.com/gohugoio/hugo/releases/tag/v0.55.6).
Verify the archive's SHA-256 against the checksum file, extract it, and install
the `hugo` executable as `hugo-0.55.6` in a directory on your `PATH`.
The archive verified for this setup has SHA-256:

```text
dee91964da19f8632dbb4a9421d5c0fa52de9d1f10df96fed7bb256919febb77
```

This Intel macOS binary runs through Rosetta on Apple Silicon. Set `HUGO_BIN`
to another path to Hugo 0.55.6 extended, or `HUGO_SOURCE_DIR` to an alternative
source directory, when needed.
